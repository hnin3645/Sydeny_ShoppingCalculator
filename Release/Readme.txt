This folder contains all releases of Shopping Amount Calculator(SAC) and Shooping Calculator(SCR), 
These two calculators have similar functions while using completely different ways to achieve.
----------------

About Shopping Amount Calculator (SAC):

Shopping Amount Calculator is a calculator that can calculate the amount of money spent each person 
after shopping which can calculate up to four users. This calculator is based on the Microsoft Excel, 
user can easily master the calculator after read several simple instructions. There are two sub-version 
intergrated in the program which are ver.qua and ver.tri, the first version is for four users and the 
second is for three, a two-user calculator is intergrated inside in both versions in term of more complicated 
conditions.
----------------

About Shopping Calculator (SCR):

Shopping Calculator is a completely open sourced offline calculator based on python. User can freely change 
the number of users that needs to calculate from 1 to 4. The Calculator can achieve more than 85% of the SAC 
with much more less size of the file.

The calculator currently have one version - V1.0.
----------------

All SACs and SCRs will update in this folder, You can clearly see the version of each calculator as they are 
showen on the title of each folder.
